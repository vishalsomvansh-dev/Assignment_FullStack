# Web Development Practical Codes

This bundle contains solutions for all 13 practical questions:
1. Concentric circles (CSS)
2. Ten horizontally aligned cards (HTML/CSS/JS)
3. To-do list (HTML/CSS/JS)
4. Dynamically generated chessboard (JavaScript)
5. Snake and ladder game (HTML/CSS/JS)
6. Random jokes using an API
7. Country-wise university search using an API
8. Express app with five routes and EJS template engine
9. REST CRUD for products (in-memory)
10. Product API + client-side rendering
11. Express + MongoDB product CRUD
12. E-commerce learning starter (products, cart, mock checkout/order history, seller panel)
13. React personal portfolio

For plain HTML projects, open `index.html` in a browser. For Express projects, open that project's folder in VS Code, run `npm install`, then `npm start` (see each README). For React portfolio, run `npm install` then `npm run dev`.

Important:
- The first 7 tasks are browser projects and generally need internet for external images/APIs.
- The in-memory CRUD task loses data when the server restarts.
- The MongoDB tasks need a running MongoDB server or Atlas connection string.
- The e-commerce task is a classroom prototype with mock/unpaid checkout. It does not process real payments. Add authentication, authorization and payment-provider verification before any real deployment.
- Replace portfolio placeholder links and contact details before submitting.
